Recto portable mode

While this file sits next to recto.exe, Recto keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the RectoData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Recto with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Recto and
%LOCALAPPDATA%\Recto) instead. If RectoData can't be written (for example on a read-only
drive), Recto says so and uses the per-user folders instead.
