# Recto

A standalone, minimal, open-source desktop PDF application.
Open PDFs, edit, annotate, organize and combine documents with fast native performance.

Run `recto.exe` on Windows, `recto` on Linux/BSD, or open `Recto.app` on macOS. The Windows portable
edition keeps its application data in `RectoData` beside the executable.
Optional OCR requires bundled model files.
