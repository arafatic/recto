# Documentation screenshots

The `recto-*.png` files currently contain historical upstream interface captures.
Renaming them does not make their contents current Recto screenshots. They are not
runtime assets and are not required to build or run Recto.

Keep their existing attribution and license records. Replace these captures with
current Recto screenshots, or remove them and their references, before using them
to present the redesigned application. `cargo xtask screenshots` uses the new
filenames for future captures.
